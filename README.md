# Экскурсия по клинике «Академия улыбки»

Самостоятельный сайт: интерактивная экскурсия по шести помещениям клиники,
карточки оборудования, документы врача и мини-игра «Бор против кариеса».

## Что внутри

    index.html                  вся страница целиком: разметка, стили, скрипты
    assets/tour/scenes/         фотографии помещений (6 шт.)
    assets/tour/equipment/      снимки оборудования (16 шт.)
    assets/tour/docs/           дипломы и сертификаты врача (5 шт. + превью)
    .nojekyll                   отключает обработку Jekyll на GitHub Pages

Внешних зависимостей нет, кроме шрифтов Google Fonts (Golos Text, Prata).
Сборка не нужна: файлы раздаются как есть.

## Публикация на GitHub Pages

Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)`.
Через минуту сайт открывается по адресу вида
`https://<логин>.github.io/<репозиторий>/`.

## Перенос на основной сайт

Положить `index.html` рядом с главной под именем `tour.html`, папку `assets`
слить с существующей. Внутренние ссылки «На сайт» и «Сведения о клинике» в
самостоятельной версии абсолютные — при переносе их можно вернуть на
относительные (`index.html`, `info.html`).
